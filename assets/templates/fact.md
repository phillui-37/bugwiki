# One sentence stating the fact as a current truth

Not "the agent then tried to run the tests". Write what is true now, so a
future reader can act on it without replaying the session.

## Evidence

The exact command, output line, or file:line that proves it. A fact whose
evidence is only the agent's prose gets `status: open`, not `verified`.

## Scope and limits

Where this holds (repo, version, platform) and where it stops holding.
