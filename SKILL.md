# bugwiki

Use before debugging or acting on recalled operational state. Resolve the installed CLI and its content root first: Bash, the repository PowerShell port and custom native adapters do not share every command or schema. Do not replace an adapter based on a filename or hash difference.

1. Search an exact error, identifier or filename with `wiki find`. Start with at most two matching nodes; follow supersession to the current end.
2. Obsolete, conflicting or expired state is not a current answer. An open fact needs verification. Inspect sources if the adapter cannot traverse links.
3. If nothing useful appears within 60 seconds, investigate directly. When a node helps, record recurrence/last_seen according to the adapter's contract.

Keep code and the machine-local knowledge store separate. Never store credentials. A solution needs real investigation cost; a fact needs traceable evidence. Preserve old state and supersession when a fact changes.

- For a write, validity/schema question or unsupported command, read [read/write contracts](references/read-write.md).
- Only for a requested transcript/dream pass, read [dream policy](references/dream.md) and [recovery](docs/dream-recovery.md).
- Only for installation/migration, read [setup](references/setup.md) and the [README](README.md).

Dream automation must not change AGENTS.md or promote global rules. The short read path does not require loading the dream or installation procedures.
